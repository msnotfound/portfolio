# **The Ultimate Design Engineering & AI Stack**

This document is a comprehensive, categorized compilation of the absolute bleeding-edge tools, platforms, AI Agent Skills (skills.sh), and Model Context Protocol (MCP) servers required to build premium, Awwwards-level spatial web applications.

## **1\. Platforms, Registries & Inspiration**

The foundational ecosystems where you find inspiration, pull components, or visually build interfaces before touching code.

### **🎨 Inspiration & Reverse Engineering**

* **Awwwards / Godly Website:** The pinnacle of interactive, animated, and spatial web design.  
* **Hoverstat.es:** The archive for brutalist, experimental, and alternative web interfaces.  
* **Behance / Dribbble:** Deep case studies (Behance) and visual UI snippets (Dribbble).  
* **Mobbin / Pageflows:** Searchable libraries of real-world UX patterns, onboarding flows, and mobile screenshots.

### **🧩 Component Registries & Templates**

* **21st.dev:** The central hub for copy-paste React components tailored for AI apps.  
* **shadcn/ui:** The gold standard for accessible, customizable, and composable React/Tailwind components.  
* **Aceternity UI & Magic UI:** Heavily animated, trendy React components (Framer Motion/Tailwind) for SaaS and AI products.  
* **Uiverse.io:** Community-driven CSS/HTML micro-interactions.  
* **MotionSites (motionsites.ai):** Prompt-as-a-service for premium animated hero sections and landing pages.

### **🏗️ Visual Builders & AI Generators**

* **Webflow / Framer / TeleportHQ / Webstudio:** The elite tier of visual development and design-to-code platforms.  
* **v0 (Vercel) / Lovable / Bolt.new:** AI agents that spin up complete React apps/components from natural language prompts.  
* **Hostinger Horizons / WebSim.ai:** Prompt-to-app full-stack builders and hallucinatory UI prototyping.

### **🌌 3D, WebGL & Spatial Platforms**

* **Spline / Womp:** Browser-based 3D design tools (like Figma for 3D/liquid clay) that export directly to React.  
* **Unicorn Studio:** Visual builder specifically for WebGL shaders, liquid distortions, and interactive particles.  
* **Dora (Dora AI):** Generates 3D animated web layouts using text prompts and handles complex scroll-tied camera math.  
* **Luma AI / Meshy:** Generative AI for instant 3D asset/model creation from text or images.  
* **Cables.gl / Shadertoy:** Visual node-based programming and GLSL code hubs for mind-bending WebGL math and shaders.

## **2\. Core Code Libraries & Engines**

The actual dependencies and engines that power the modern, high-performance web.

* **Motion (motion.dev):** The independent evolution of Framer Motion. The ultimate hybrid engine for UI physics, layout animations, and gestures.  
* **GSAP (GreenSock):** The heavy-duty timeline animation engine for massive, cinematic scroll-triggered websites.  
* **React Three Fiber (R3F) & Drei:** The declarative React ecosystem for managing Three.js scenes, complete with a massive drop-in component registry (Drei).  
* **Theatre.js:** A cinematic motion graphics animation studio that lives directly inside your browser's DevTools for choreographing 3D/DOM scenes.  
* **Rive:** The state-machine-driven replacement for Lottie; used for highly interactive, game-like vector UI animations.  
* **Orillusion:** A pure WebGPU engine for rendering massive 3D scenes at 120fps.  
* **AGS & Eww:** Desktop-level UI engines for building heavily animated Linux/terminal environments (using GTK/SCSS or Rust/Yuck).

* **broomva/symphony-forge:** The engine for creating "dark glass" Web3/AI SaaS landing pages.

* **motion-design-patterns:** Teaches AI to orchestrate complex Framer Motion stagger animations and proper spring math.

## **4\. MCP Servers (Model Context Protocol)**

The interactive plugins that give your AI agent API access to tools, browsers, live documentation, and external software.

### **🌉 UI, Figma & Design Integration**

* **21st.dev Magic MCP:** Turns your IDE into v0. Generates multiple UI variations using the 21st.dev registry and drops production-ready code into your project.  
* **Official Figma MCP:** Bi-directional sync. Pulls exact tokens from Figma, or pushes a local localhost React component *back* into a Figma frame.  
* **Gemini Design MCP:** Enforces strict frontend architecture by isolating UI logic from backend logic.  
* **Shadcn / FlyonUI / Storybook MCPs:** Gives the agent direct access to verified UI blocks and your company's existing component registry.  
* **Framer / Supernova MCPs:** Extracts Framer nodes into React code and enforces enterprise design system tokens securely.  
* **MCP-UI (Standard):** Allows the AI to render fully interactive React components inside the chat window before you paste the code.

### **🕹️ 3D, Media & Video Generation**

* **Three.js / Context7 MCPs:** Connects the AI to the live, up-to-date documentation for Three.js and cutting-edge libraries to prevent hallucinated math.  
* **Dora / Meshy MCPs:** Generates fully rigged 3D models and spatial web layouts directly into your public/ folder.  
* **BlenderMCP:** Creates a websocket connection allowing the AI to write Python scripts to control and optimize a live Blender session.  
* **Higgsfield / Runway Gen-3 MCPs:** Connects the IDE to cinematic AI video models to generate looping backgrounds and MP4 assets asynchronously.  
* **Rive / Lottie Creator MCPs:** Reads state machines and generates vector UI animations via natural language.

### **🕵️ QA, Automation & Scraping**

* **Playwright / Puppeteer Performance MCPs:** The AI spins up a headless browser, runs your animations, takes screenshots, profiles the frame rate, and refactors slow code.  
* **Chrome DevTools / Firecrawl / Apify MCPs:** The AI drives a browser to scrape Awwwards sites, bypass bot protection, extract computed CSS, and clone layouts.  
* **CodeRabbit MCP:** Acts as a senior code reviewer to catch "AI slop," layout shifts, and bad React architecture in real-time.

### **🧠 System Infrastructure & Logic**

* **Sequential Thinking MCP:** Forces the AI into a step-by-step reasoning loop before attempting complex WebGL or physics math.  
* **Supabase / Vercel MCPs:** Allows the agent to design database schemas, apply RLS, and deploy the site without leaving the editor.  
* **Memory / Postgres / Bash MCPs:** Gives the AI long-term context memory, access to read real user database schemas, and terminal access to run scripts.

## **5\. Master Concepts (Human Skills)**

To direct these AI tools effectively, you must understand the underlying physics of the web:

1. **Motion Physics:** Spring math (mass, stiffness, damping), custom Bezier easing, and Layout animations.  
2. **GPU Architecture:** Repaint vs. Composite triggers, offloading to the GPU (transform / opacity only).  
3. **Spatial Math:** Fragment/Vertex shaders (GLSL), Quaternions, and 3D coordinate systems.  
4. **Tactile UI:** Kinetic typography, fluid CSS Grid/Container queries, generated CSS noise, and dynamic sub-pixel blurring.
